# FinanceX-ClonePro

A modern, responsive fintech landing page built with Next.js 14, TypeScript, and Tailwind CSS. This is a frontend-only implementation inspired by the Finance X Webflow theme.

## 🚀 Features

- **Modern Design**: Dark theme with vibrant lime/green accents
- **Fully Responsive**: Optimized for mobile, tablet, and desktop
- **Interactive Components**: Animated counters, carousels, and smooth transitions
- **Performance Optimized**: Built with Next.js 14 and optimized for speed
- **TypeScript**: Fully typed for better development experience
- **Accessible**: Semantic HTML and ARIA compliance

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion + CSS animations
- **Font**: Inter (Google Fonts)

## 📦 Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd financex-clonepro
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🚀 Deployment

This project is optimized for deployment on Vercel:

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy with zero configuration
